# Food Diary 

Простой и удобный дневник питания для отслеживания калорий, макронутриентов, воды и привычек питания. Помогает вести здоровый образ жизни, контролировать вес, готовиться к соревнованиям или просто лучше понимать, что ты ешь.


## Основные возможности

- Быстрое добавление приёмов пищи (поиск по базе продуктов, сканирование штрих-кода, фото распознавание — в планах)
- Автоматический расчёт калорий, белков / жиров / углеводов (БЖУ), сахара, клетчатки, воды
- Ежедневные / еженедельные / ежемесячные отчёты и красивые графики
- Установка целей: калории, макросы, дефицит/профицит, интервальное голодание
- История приёмов пищи с поиском и фильтрами
- Локальное хранение данных (без обязательной регистрации) + опциональная синхронизация через облако
- Тёмная / светлая тема
- Поддержка нескольких языков (русский + английский из коробки)

## Технологии

- Frontend: React Native / Flutter / Vue 3 + Vite / React + TypeScript  
- Backend (если есть): Node.js / Express / Django REST Framework / Firebase  
- База данных: SQLite (локально) / PostgreSQL / Firebase Firestore  
- Аутентификация: JWT / Firebase Auth (опционально)  
- Графики: Chart.js / Recharts / fl_chart  
- Сканер штрихкодов: expo-barcode-scanner / ZXing / ML Kit  
- Хранение: AsyncStorage / Hive / SharedPreferences / Room
